UK Tax Calculator & UKVI Sponsor Licence

This repository is a Java console project. There is no web front-end; all logic runs from the command line using plain javac / java.

Modules

1. UK Accounting & Tax Calculator

Source file: src/main/java/UKAccountingSystem.java

Calculates income tax, NIC, corporation tax, and dividend tax for sole traders, landlords, and limited companies.

2. UKVI Sponsor Licence Console App

Source file: src/main/java/ukvi/UkviSponsorLicenceApp.java

Builds a UKVI sponsor licence readiness report: key personnel, compliance checklist, supporting documents, and a READY / NOT READY summary.

How to Compile & Run

Compile all sources

javac -d out $(find src/main/java -name "*.java")

Run the Tax Calculator

java -cp out UKAccountingSystem

Run the UKVI Sponsor Licence App

java -cp out ukvi.UkviSponsorLicenceApp

Requirements

  • Java 11 or later
  • No build tool (Maven / Gradle) required – plain javac is sufficient
